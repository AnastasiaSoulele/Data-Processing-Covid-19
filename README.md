# Data Processing — Effects of COVID-19 on Trade

A Python data analysis project exploring the effects of COVID-19
on international trade, combining SQL database design with
Python-based analysis and visualization.

##  Overview

The project analyzes a real-world dataset of COVID-19's impact
on global trade, processes it through a relational database,
and produces insights via Python data analysis.

##  Files

| File | Description |
|------|-------------|
| `main.py` | Python data analysis & visualization |
| `Database EffectsOfCovid.sql` | SQL schema & queries |
| `DataBase Schema.pdf` | Visual database schema diagram |
| `effects-of-covid-19-on-trade.csv` | Raw trade dataset |
| `Αναφορά Python_Project.pdf` | Full project report (Greek) |

##  Dataset

Real-world CSV dataset containing international trade metrics
during the COVID-19 pandemic period, used for trend analysis
and statistical processing.

##  How to Run

```bash
pip install pandas matplotlib
python main.py
```
